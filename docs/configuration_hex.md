# Configuration hex

The `config` row of the performance overlay (Shift+Ctrl+Alt+P) is every
setting the player has, packed into hex, so a screenshot of a report
carries the configuration that produced it. This is how to read it.

Generated by `tools/configHexTable.ts`; do not edit by hand. A test
regenerates it and fails if this file no longer matches the client.

Format version: **1**

## Layout

| Offset | Bytes | What |
|---|---|---|
| 0 | 1 | Format version. Anything else means a different table. |
| 1 | 1 | Number of flag bytes that follow (currently 9). |
| 2 | 9 | The on/off settings, one bit each, first in bit 0 of the first byte. |
| 11 | 1 | Number of value bytes that follow (currently 56). |
| 12 | 56 | The numeric settings, one byte each, each stored as value + 128. |
| 68 | 2 | Language, two ASCII letters (`65 73` is `es`). |
| 70 | 2 | Texture pack digest, `0000` when the original textures are in use. |

Total: **72 bytes**, 144 hex characters.

## Worked example

```
01 07 ff 7b ... 4a 80 81 ... 65 73 0000
```

`01` version 1, `07` seven flag bytes, then the flags, then the count of
value bytes and the values (`80` is 0, `81` is 1, `7f` is -1), then `65 73`
for Spanish and `0000` for no texture pack.
